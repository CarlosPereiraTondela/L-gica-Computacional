💻 Introdução à Lógica Computacional

O que é Lógica Computacional?

A lógica computacional é uma área da lógica matemática aplicada à ciência da computação. A sua relação com a ciência da computação e a engenharia é comparável à ligação da lógica matemática com a matemática ou da lógica filosófica com a filosofia.

O foco deste domínio é explorar princípios, métodos e sistemas que permitem representar e manipular raciocínios lógicos num contexto computacional, aplicando-os a problemas computacionais. Ela serve como uma ponte entre a matemática e a ciência da computação, com aplicações em algoritmos, linguagens de programação e inteligência artificial, sendo fundamental para o desenvolvimento e a evolução da computação moderna.

🔗 Relação com a Ciência da Computação

A lógica computacional influencia diversas áreas:

  • Algoritmos: Baseados em raciocínios lógicos e operações booleanas.
  • Linguagens de Programação: Fundamentais para construir e interpretar código.
  • Sistemas Inteligentes: Criar sistemas que raciocinam autonomamente.
  • Verificação de Software: Garantir que os programas funcionem corretamente.

🌟 Importância na Programação

Ajuda a:

  • Modelar problemas de forma estruturada.
  • Provar a precisão e correção através de métodos formais.
  • Apoiar áreas como a inteligência artificial, com conceitos de inferência e dedução.

🕰️ História e Evolução

Aristóteles

Desenvolveu os fundamentos do raciocínio dedutivo, estabelecendo as bases da lógica formal.

Leibniz (século XVII)

Propôs a ideia de uma linguagem lógica universal que pudesse representar todo o conhecimento humano.

George Boole (1847)

Criou a álgebra booleana, fundamentando a lógica matemática que seria essencial para a computação.

Turing, Church e Gödel (século XX)

Desenvolveram os fundamentos teóricos da computação moderna, incluindo a máquina de Turing e o teorema da incompletude de Gödel.

Hoje

Aplicações em inteligência artificial, linguagens de programação e verificação de software.

🧩 Fundamentos de Lógica

Lógica Proposicional

A lógica proposicional é um ramo da lógica matemática que lida com proposições ou afirmações que podem ser classificadas como verdadeiras ou falsas. Cada proposição é representada por uma variável (geralmente, letras como p, q, r), que assume valores de verdadeiro (V) ou falso (F).

Conectores Lógicos

Os conectores lógicos são usados para combinar proposições e formar novas proposições:

Conector Símbolo Descrição Exemplo
E (AND) ∧ Verdadeiro apenas se ambas as proposições forem verdadeiras p ∧ q
OU (OR) ∨ Verdadeiro se pelo menos uma das proposições for verdadeira p ∨ q
NÃO (NOT) ¬ Inverte o valor lógico da proposição ¬p
SE...ENTÃO (CONDICIONAL) → Falso apenas quando a primeira é verdadeira e a segunda é falsa p → q
SE E SOMENTE SE (BICONDICIONAL) ↔ Verdadeiro quando ambas têm o mesmo valor lógico p ↔ q

Tabelas de Verdade

Tabelas de verdade mostram todos os valores possíveis das proposições compostas:

🔄 Paradigmas de Programação

Programação Imperativa

Foco em como algo deve ser feito (sequência de comandos). O programador controla o estado do programa com variáveis, loops e estruturas condicionais.

Exemplos de Linguagens:

  • C
  • Python
  • Java

Conceitos Centrais:

  • Variáveis mutáveis
  • Loops (for, while)
  • Estruturas condicionais (if-else)
# Exemplo em Python (Imperativo)
# Soma de números em uma lista
def soma_lista(lista):
    total = 0  # Variável mutável
    for numero in lista:  # Loop
        total += numero  # Modificação de estado
    return total

numeros = [1, 2, 3, 4, 5]
print(soma_lista(numeros))  # Saída: 15

Programação Funcional

Foco em o que deve ser feito (funções e transformações de dados). Uso de funções puras, imutabilidade e recursão.

Exemplos de Linguagens:

  • Haskell
  • Lisp
  • Scala

Conceitos Centrais:

  • Funções puras
  • Imutabilidade
  • Recursão
  • Funções de alta ordem
-- Exemplo em Haskell (Funcional)
-- Soma de números em uma lista
somaLista :: [Int] -> Int
somaLista [] = 0  -- Caso base
somaLista (x:xs) = x + somaLista xs  -- Recursão

-- Uso:
-- somaLista [1, 2, 3, 4, 5]  -- Retorna 15

Comparação entre Paradigmas

Característica Imperativo Funcional
Estado Mutável Imutável
Foco Como fazer (passos) O que fazer (transformações)
Controle de fluxo Loops, condicionais Recursão, composição de funções
Funções Podem ter efeitos colaterais Funções puras (sem efeitos colaterais)
Exemplo típico Modificar uma estrutura de dados Criar uma nova estrutura de dados transformada

    pares = []
    for numero in lista:
        if numero % 2 == 0:
            pares.append(numero)
    return pares

Fatorial de um Número

def fatorial(n):
    resultado = 1
    for i in range(1, n+1):
        resultado *= i
    return resultado
fatorial :: Int -> Int
fatorial 0 = 1
fatorial n = n * fatorial (n-1)

🔌 Aplicações Práticas

Exemplo com Arduino: Piscar LED

Componente necessário: Arduino Uno R3

Código

void setup() {
  pinMode(LED_BUILTIN, OUTPUT); // Define o pino do LED como saída
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH); // Liga o LED
  delay(1000);                     // Espera 1 segundo
  digitalWrite(LED_BUILTIN, LOW);  // Desliga o LED
  delay(1000);                     // Espera 1 segundo
}

Explicação

A placa UNO R3 tem um LED integrado ('L') que pode ser controlado pelo programa. O código acima faz o LED piscar a cada 1 segundo (1000ms).

Se alterarmos o delay para 500ms, o LED piscará duas vezes mais rápido.

Conclusão

A lógica computacional pode ser aplicada de maneira distinta em paradigmas imperativo e funcional. Enquanto na programação imperativa controla-se diretamente o estado do programa e o fluxo de execução, na programação funcional foca-se em funções puras e imutabilidade, utilizando recursão e funções de ordem superior para resolver problemas de forma declarativa.

Ambos os paradigmas têm suas vantagens e são amplamente utilizados na indústria de software, sendo a compreensão da lógica subjacente essencial para se tornar um programador eficaz em qualquer paradigma.
